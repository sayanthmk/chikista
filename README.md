# 🩺 Chikitsa

**Chikitsa** is a medical app built using Flutter. It provides a user-friendly interface for patients to easily access medical resources, appointments, and more.

---

## 🚀 Features

- 🔐 Authentication
- 📅 Appointment Booking
- 📋 Medical Record Management
- 🔔 Notifications
